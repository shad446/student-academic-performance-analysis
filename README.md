## 🎓 Student Academic Performance Analysis

**Project Overview**

Developed an interactive dashboard to analyze student exam performance and explore factors associated with academic outcomes.

**Business Objectives**
- Analyze student performance across mathematics, reading, and writing.
- Explore score differences by gender and parental education level.
- Examine how lunch type and test preparation relate to academic outcomes.
- Present data-driven insights to support educational decision-making.

**Tools & Technologies**
- Python
- Pandas
- Matplotlib
- Plotly
- Streamlit

**Project Deliverables**
- Interactive academic performance dashboard
- Data visualizations and exploratory analysis
- Insights to support evidence-based educational planning
